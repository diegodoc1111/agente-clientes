# Sellbird: el agente que te consigue clientes

Guía gratis en español de [@soydiegoosorio](https://instagram.com/soydiegoosorio) para instalar Sellbird (antes Harvey) con Claude Code: busca negocios que necesitan lo que vendes, encuentra al que decide, le escribe un correo personalizado y sigue la conversación hasta agendar la cita.

**Página:** https://diegodoc1111.github.io/agente-clientes/
**Repositorio de Sellbird:** https://github.com/ethanplusai/sellbird (AGPL-3.0, de sus creadores; esta guía no está afiliada a ellos)

## Fuentes verificadas (18-nov-2026)
- README oficial de Sellbird (https://github.com/ethanplusai/sellbird): funciona con el plan Pro o Max de Claude a través de Claude Code (sin llave de API); busca negocios gratis en OpenStreetMap; encuentra al dueño o gerente y verifica el correo; envía desde Gmail/Google Workspace (unos 7 USD al mes), Microsoft 365 o SMTP; recomienda un dominio de envío aparte y calentamiento (TrulyInbox); cada correo espera aprobación en la bandeja de salida hasta que se active el piloto automático; instalación guiada con `git clone`, `cd sellbird`, `claude` y "set up Sellbird for me"; versión alojada sellbird.ai en acceso anticipado.
- Reglas y entregabilidad: https://github.com/ethanplusai/sellbird/blob/main/docs/deliverability.md
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup
